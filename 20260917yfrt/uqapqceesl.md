# 「抗疫人文关怀」隔离点的高考男孩

> 更新时间：2026-09-17 (UTC+8)

**我不下车，谁也别劝我！**

“我不下车，从哪里拉来还给我送哪儿去，谁也别劝我....”

天色渐暗，防护面屏上的雾气让我看不清是谁在最后一排坚决不下车，只是听到一个年轻的声音，坚决而愤怒，已经连续工作超过八个小时了，紧急被抽调来疫区隔离点支援，心理和身体上的疲惫让我对这个声音感到了一丝烦躁。队友说：“都下车了，就剩这一个，说啥也不动。”我拖着不再轻松的双腿走到转运车的最后一排，一个年轻讲究的高中男生坐着，怀里抱着自己的包，看着手机，无视我的到来。

“小伙子，隔离点到了，我们要下车了，我带你去安排房间，晚饭还没吃呢吧？一会儿安排好住宿，我们先吃饭。”知道他的情绪，我准备以“大姐姐”的身份打感情牌。

“不下！不吃！”他的眼睛和手始终没离开手机，看着车外焦急等待的司机和负责转运的同志，我继续沟通。

“你在哪上高中啊？是次密接人员吧？家里人谁一起来的？”

“临颍二高，我侄女是博雅幼儿园的，也不一班，在家隔离还不行啊？非要拉过来，让我们来的时候说好去酒店，啥都不用带，现在呢？拉的这是哪儿？”

“小伙子，你没进去怎么知道里面什么都没有呢？我们已经铺好了床，买了新的水壶，马上也会安排送餐，相信我们，相信学校，相信政府会给我们慢慢解决，保证咱们隔离时期的生活质量。”

听到这里，他没再说什么，似乎被我说动了，“那我和妈妈，侄女能住一个房间吗？我们的东西都在一起。”

“根据防疫要求，一个成年人可以陪同一个14岁以下的孩子同住，所以你得自己住个房间。这样吧，我帮你们分东西，缺什么你告诉我，我再帮你解决，可以吗？”

“行，好，下车！”他不情不愿的下车了，跟着我来到安排好的地方，我帮他把东西收拾好，开始送餐了，他似乎没什么胃口，只是一直没离开手机。

**到底什么时候可以出去？**

第二天工作开始，当我敲开他的房门时，他很疲惫也很焦虑。“到底什么时候可以出去？”他一遍一遍问，我看见他早饭又没动。不禁有一丝疑问，隔离地点的生活保障，今天都在一点点的改善，大家缺的物资和合理要求也在一点一点解决，我问他：“缺什么吗？小恺”我记住了他的名字，喊了他的名字，他有点惊讶，但语气缓了下来，“什么都不缺”。他简单的回答。“我这几天就是要出去，我必须出去！”他坚决要求。“有什么地方不舒服吗？”我怕他身体不舒服，“没有，就是必须出去，你必须给领导申请。”我心里的疑惑更大了，因为工作还没完成，我只能带着疑惑离开了。

中午我突然想起了我们的叙事护理，就决定用自己的能力和这个大男孩儿叙一叙。

下午我早早地换了衣服来到了隔离区，完成了基本工作外，我来到了他的门前，“小恺，怎么样，还需要什么吗？”我看他中午饭又没怎么动。

“不缺什么了”

“下午要上网课吗？”

“今天的网课已经结束了，我什么时候能出去？”他似乎只有这一个问题。

**终于知道了原因**

“小恺，你看，这里都是隔离人员，我们既然来到这里，就安心地隔离，这对我们，对我们的家人都好，我看很多都是幼儿园的小朋友，还有七十多岁的爷爷奶奶，大家都做好了在这最少14天的准备，你为什么非要出去呢？有什么难处说出来，我会尽我的全力为你解决的。”

“我马上要参加单招考试了....”他急的红了眼睛，坐在那里，我一听，心里也咯噔一下，我知道高考对一个学生意味着什么，此刻只想弄清楚状况，看能不能帮上他。

“什么时间？”我问到。

“4月8号。”他语气哽咽。

我算了算，如果不出意外的话，按14天隔离，那么4月8号他还不能出去。“小恺，你放心，虽然我不清楚我能不能帮你解决这个事，但是我一定先帮你去咨询沟通，你放心！好好吃饭，上课，认真准备着。”

“谢谢姐，我这边也随时关注着学校的动态。”他没了焦虑，坦然接受了我的建议。

**一张张能量满满的小纸条**

工作结束后我找到了驻扎在我们隔离点的教育局的文局长，向他说明了情况，他一边向上面反映解决，一边让我转达，让那个男孩放心，并联系了移动，联通公司为需要上网课的手机赠送了免费的流量。

童话里英雄总是得天独厚，犹如救世主一般，光辉英勇，万中无一，凌驾于芸芸众生之上，然而在现实中大家都期待着超级英雄的降临，是一个又一个普通人把自己的所能拼凑起来，然后才有了划破黑夜的光亮。

由于防疫要求，我和他选择微信联系，自己每次来到他的门外，我都会给他一张能量满满的小纸条，“小恺，如果让你给现在的状态取个名字，你会叫它什么？”看着他又一顿没吃的饭，不再整理的头发，我问他。

“忧心忡忡。”

“那你觉得隔离的生活除了让你担心单招考试外，还有哪些影响呢？有没有好的方面？”

“其实除了担心耽误单招考试，在这里还是很安静的。不被人打扰，领导也赠送了流量，大白们也很暖心，尽全力解决我们的困难。”说到这，第一次看到这个大男孩的笑脸。

**谢谢你，大白姐！**

“今天班主任联系我了，她说虽然没有正式的文件，但是考试应该会延迟，即使不延迟，也会联系教育局帮我解决的，其实这对于我来说，也算是个好事，我学习一般，正好有更多的时间复习。”他的表情第一次这么轻松。

“是的，我向我们教育局反映了你的情况，这种情况不是只你一个人有，相信都会妥善解决的，你就安心复习，也要注意身体，我看你都没好好的吃饭这几天，缺什么尽管告诉我。”

“谢谢你大白姐，听你说完心里轻松多了，其实我们现在只是被困在这里，可是有些人却被困在了那个冬天，所幸的是凛冬已过，皓月长明，疫情终逝，这人间仍是星河滚烫，江山如故，我们只是在隔离，而你们还要为我们工作，想想来的时候，我真的不应该那样。”说着他眼圈红了。

之后每次来到他的房间，小恺的精神状态都很好，朝气蓬勃，恢复到他这个年龄该有的样子。

一天的工作又开始了，我问小恺：“还需要什么吗？”

他有点不好意思的说：“特别想喝绿茶。”

安排！
