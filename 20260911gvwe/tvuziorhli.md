# 成都南希医院促排促排卵一共要花多少钱，促排+促排卵收费并不高！

> 更新时间：2026-09-11 (UTC+8)

成都南希医院促排费用是1.2-1.5万元左右，促排卵费用是在0.5万左右，所以促排+促排卵一共在1.7-2万不等，不过每个患者采用的促排卵药物和剂量不同，费用会有差异。一般来说，成都西囡做试管的费用会比公立医院贵一些，一个完整流程下来，总费用在5-8万左右，主要包括术前检查费用、药品费用和手术费用这三大部分。

成都南希医院目前能够开展AIH/精子人工授精、第一代和第二代试管婴儿技术，在该医院做试管成功率是较高的。而不孕不育患者除了成功率还比较关心的就是费用问题，下面就是成都南希医院试管相关费用情况：

- 1. 术前常规检查：费用大概6500元左右，包括男方的精液常规分析及精子形态、血型、传染病、染色体等，女方有内分泌、彩超、甲功、肝肾功、染色体等等；
- 2. 进周前预处理或降调：若是采用长方案，促排卵开始前就会使用降调药物，为促排卵期间能更好的启动多个卵泡同时发育做准备，一般用药后14天开始促排卵，而降调药物费用大概在1800元左右；
- 3. 促排卵：试管婴儿促排卵费用会根据使用的药物不同而变化，一般促排卵药分国产和进口，进口药物价格较高，同时根据个人卵泡生长情况，用药时间及治疗费用也会不同，费用在1.2-1.5万不等；
- 4. 手术费用：IVF费用1万元左右，ICSI需要增加4500元的费用，如果胚胎数目多，胚胎培养、保存及解冻费还需相应增加，进行鲜胚移植的话，费用是1700元左右，若是冻胚移植加上后期胚胎复苏费、移植手术费、内膜准备，约8000元左右。

试管移植后，需要黄体支持，就会额外使用黄体酮，地屈孕酮，雪诺酮这类药物保胎，药费大概在1000-2000元左右。其实在整个试管过程中，变数最大的就是促排卵费用，此部分费用也是占比较大的。
