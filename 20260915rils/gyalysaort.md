# 产检彩超检查什么时候做

> 更新时间：2026-09-15 (UTC+8)

产检彩超检查一般在孕期的特定时间段进行，每个阶段检查的重点不同，通常在孕早期（11-14周）、孕中期（20-24周）和孕晚期（28-32周）分别进行。不同时间的彩超检查能评估胎儿的生长发育、排除异常、监测健康状况，并为孕妇提供科学的健康指导。

1.孕早期（11-14周）：评估胎儿基本情况

在孕早期的彩超检查中，主要进行NT（颈项透明层厚度）筛查，检查胎儿是否存在染色体异常或心脏发育异常风险。

检查内容：胎囊位置、胎心胎芽是否正常、胎儿数目，NT厚度等。

建议事项：孕早期超声可采用经腹部或经阴道方式，检查前需适当憋尿以提高成像效果。

2.孕中期（20-24周）：排畸检查的黄金期

这是孕期最重要的一次超声检查，常被称为“大排畸”。此阶段通过详细的彩超扫描，评估胎儿器官是否存在结构异常。

检查内容：重点检查胎儿心脏、四肢、大脑、脊柱、内脏器官等发育情况，发现如脊柱裂、先天性心脏病等问题。

建议事项：孕妇需根据医嘱按时就诊，检查当天保持良好休息，确保胎儿配合检查。

3.孕晚期（28-32周）：监测胎儿生长发育

孕晚期彩超旨在进一步评估胎儿的生长状况、羊水量以及胎盘功能，为分娩做好准备。

检查内容：胎儿的体重、胎位、羊水指数、胎盘成熟度等，同时评估胎儿是否存在发育迟缓等情况。

建议事项：孕晚期检查无需憋尿，检查当天避免进食过饱，放松心情。

4.根据需要的额外检查时间

除了常规三次彩超，有些特殊情况需要增加检查次数。例如：

孕5-6周：如有阴道出血或腹痛，可做早孕彩超确认胎儿存活及宫内妊娠。

36周后：检查胎位和分娩方式评估，监测胎盘老化。

温馨提醒

按时进行彩超检查，既是对胎儿发育的有效监测，也有助于减少孕期风险。如果孕期有任何不适，应及时就医，并配合医生的建议选择必要的超声检查。健康的孕期离不开科学的产检安排和良好的生活习惯。
